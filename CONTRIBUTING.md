# Contributing to the Python Student Project

Thank you for contributing to this beginner-friendly Python project.

## 1. How to Report an Issue

If you find a problem:

1. Open the project's **Issues** section.
2. Create a new issue.
3. Clearly describe the problem.
4. Include steps to reproduce the problem, if possible.

## 2. How to Suggest a Feature

To suggest a new feature:

1. Open the project's **Issues** section.
2. Create a new issue.
3. Describe the feature you would like to add.
4. Explain why the feature would be useful.

## 3. How to Create a Branch

Create a separate branch before making changes.

```bash
git checkout -b feature-name
```

Use a clear and meaningful branch name.

## 4. How to Make Changes

1. Make the required changes in your branch.
2. Keep changes small and focused.
3. Write clear and readable Python code.
4. Save your changes.

Then commit the changes:

```bash
git add .
git commit -m "Describe your changes"
```

## 5. How to Test Changes

Before submitting your changes:

1. Run the Python program.
2. Check that the program works as expected.
3. Check that your changes have not caused new problems.

## 6. How to Create a Pull Request

After testing your changes:

1. Push your branch to the repository.
2. Open the repository.
3. Create a new pull request.
4. Describe the changes you made.
5. Submit the pull request for review.

## 7. Basic Coding Guidelines

- Use clear and meaningful names for variables and functions.
- Keep the code simple and easy to understand.
- Use consistent indentation.
- Add comments when they are helpful.
- Avoid unnecessary code.
- Test your changes before creating a pull request.

Thank you for contributing!
