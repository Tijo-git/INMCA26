# Frequently Asked Questions

## Do I need Python 2 or Python 3?

Install Python 3. Python 2 is retired and is not needed for this project.

## Do I need to install any packages?

No. The scripts in this project use Python's standard library and do not require packages from PyPI.

## Why does Windows use `py` while macOS and Linux use `python3`?

The Windows Python launcher, `py`, can select an installed Python version. On macOS and Linux, `python3` is commonly used to distinguish Python 3 from any system `python` command.

## How can I check which Python version is installed?

Run `py --version` or `python --version` on Windows, and `python3 --version` on macOS or Linux. The result should identify Python 3.

## Can I have more than one Python version installed?

Yes. Multiple versions can coexist. Use the appropriate launcher or command to select the version you intend to run.

## Do I need an editor to install Python?

No. Python can be installed and verified from a terminal. A code editor is optional and can be installed separately.

## Where should I download Python?

Use the official downloads page at [python.org/downloads](https://www.python.org/downloads/). Linux users may also use their distribution's official package manager.
