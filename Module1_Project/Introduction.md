# Introduction

Python is a general-purpose programming language used for automation, education, data analysis, web development, and many other tasks. This project contains small Python scripts and uses only the Python standard library, so no additional packages are required to get started.

This documentation explains how to install Python, confirm that it is available from a terminal, and resolve common setup issues. The steps are written primarily for Windows, with notes for macOS and Linux.

## What You Will Need

- A supported Windows, macOS, or Linux computer
- An internet connection to download Python
- Permission to install software on the computer
- A terminal: PowerShell or Command Prompt on Windows, Terminal on macOS, or a terminal emulator on Linux

Download Python only from the official website: [python.org/downloads](https://www.python.org/downloads/).
